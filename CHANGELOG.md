# Changelog

## 0.1.0 — Initial demo

- Frontend-complete FreelancePilot demo: landing page, demo login, dashboard,
  projects (list + detail), proposals, analytics, settings, AI assistant.
- Mock data layer (`src/lib/data/`) standing in for a real backend, with a
  data-access interface designed to be swappable for real API calls.
- Bilingual (EN/FA) support with full RTL layout mirroring, dark mode, and
  a mobile navigation drawer.
- Accessibility-validated chart color palette (see `docs/TESTING.md`).
- Full documentation suite under `docs/` — see `docs/LIMITATIONS.md` for
  what's real vs. simulated.
